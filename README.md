# Car-Price-Prediction-
•	Built a Car Price Prediction model using Linear Regression to estimate vehicle resale values.
•	Handled data preprocessing: missing values, categorical encoding, and feature scaling.
•	Trained and validated regression models; evaluated with RMSE, MAE, and R² Score.
•	Implemented model persistence using .pkl files for deployment and live predictions.
•	Debugged and resolved issues like Internal Server Errors during model loading.
•	Showcased end-to-end ML pipeline: data → model → deployment.
